# 泸州鬼麻将

> 全网都找不到泸州规则的麻将，连输6把之后我严重怀疑：欢乐麻将和雀魂本质就是充钱才能胡牌的游戏。于是自己开发了一个开源的泸州鬼麻将——112张牌、血战到底、无鬼×8封顶40分，规则全公开，不服来战。

血战到底 · 红中鬼牌 · 换缺制 · 不可吃。线上地址：https://maj.liushunqi8.com ｜ 作者博客：https://liushunqi8.com（更猎奇的在里面）

## 规则

- **牌**：万、筒、条各 36 张 + 红中 4 张 = 112 张。红中=鬼牌（万能，可替任意牌）。
- **人数**：4 人（单机可加电脑）。
- **换缺制**：开局不定缺；胡牌时手牌+副露必须缺至少一门（三门齐全不能胡）。
- **红中**：可以打出；打出的红中别人不能碰/杠/胡。无红中胡牌叫"无鬼"，得分×8。
- **血战到底**：一家胡牌不结束，继续打到三家胡或流局。
- **一炮多响**：一张牌多人可胡。
- **不可吃**，可碰/杠。

### 算分（2→5→10→20→40，跳过4，40封顶）

| 番数 | 分数 |
|---|---|
| 0番（平胡） | 2 |
| 1番 | 5 |
| 2番 | 10 |
| 3番 | 20 |
| 4番+ | 40（封顶） |

无鬼×8后同样40封顶。例：平胡自摸（1番）=5分；无鬼平胡自摸=5×8=40（封顶）。

### 番型

| 番型 | 番 |
|---|---|
| 平胡 | 0 |
| 大对子（碰碰胡） | 2 |
| 小七对 | 4 |
| 豪华七对（七对含杠） | 5 |
| 清一色 | +4 |
| 自摸 | +1 |
| 杠上花 | +2 |
| 杠上炮 | +1 |
| 抢杠 | +1 |
| 根（每根） | +1 |

根 = 杠（明/暗/补）+ 红中（每张红中算 1 根）。

### 杠

| 杠 | 得分 |
|---|---|
| 直杠（点杠） | +4（点杠者出） |
| 补杠（碰后加杠） | +2/家 |
| 暗杠 | 不下雨（无即时杠钱），只计1根 |

暗杠是主动技能：手里有4张相同的牌，摸牌后可选择是否暗杠。暗杠不能被抢；杠后摸岭上牌。没胡牌的话，暗杠白开一分钱拿不到。

抢杠胡：补杠时他人可胡该牌，杠不算，补杠者算点炮。

### 流局

1. **查花猪**：手牌+副露留了三门花色 → 赔每人 40 分。
2. **查叫**：没下叫的赔每个下叫的人。
3. 没叫的人之前杠赢的分退回。

## 工程

- `shared/mj-core.js`：纯逻辑（胡牌判定含鬼牌回溯、番型、流程），`shared/test-mj.js` 测试（54断言）。
- `client-template.html`：前端（SVG真牌面、自适应横竖屏）；`worker-src.js`：DO 房间 + WebSocket 服务器仲裁。
- `build-mj.js` 打包 → `dist/worker.js`；部署：`python3 ../richman/deploy-do.py <account> maj-game dist/worker.js`。
- 路由：`maj.liushunqi8.com/*` → `maj-game`（Worker 名）；DO：`ROOMS` / `GameRoom`。
